# executor — 3단계 정리기 (자리만)

**착수 금지.** 인계서 5장 규칙 11: 2단계 관문(정답셋에서 '확정' 오판 0건)을 통과하기 전에는 이 폴더에 코드를 쓰지 않는다.

착수할 때 지킬 것 (인계서 5장 요약)
- 승인된 계획서에 있는 것만 처리한다. 계획 뒤 크기·해시가 바뀐 파일은 건너뛰고 보고한다.
- 삭제 기능은 만들지 않는다 (`tests/test_safety_static.py`가 이 폴더도 검사한다).
- 덮어쓰지 않는다. 대상에 파일이 있으면 멈춘다.
- 먼저 적고 나서 한다(작업 일지). 정전 뒤 이어 하기·되돌리기가 가능해야 한다.
- 기본은 모의 실행. 실제 실행은 확인 문구를 직접 입력해야 하고 작은 묶음부터.
- 드라이브 간 이동 = 복사 → 해시 검증 → 기록. 원본은 그대로 두고, 원래 날짜를 대장에 남긴 뒤 복사본에 되살린다.
- 시작 전 대상 드라이브 남은 공간을 검사한다.
- 이 폴더의 코드는 만든 세션이 아닌 **다른 세션**이 처음 보는 눈으로 검토한다.
