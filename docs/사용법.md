# 진단기 사용법

## 1. exe 받기

1. GitHub 저장소 → **Actions** → 「시험·빌드」 → 초록색(성공) 실행 하나를 연다.
2. 아래 **Artifacts**의 `filetidy-windows-exe`를 내려받아 압축을 푼다.
   - `filetidy-scan.exe` — 진단기
   - `filetidy-testkit.exe` — 합성(가짜) 정답셋 생성기 (개인 PC에서 시험해 볼 때)
   - `SHA256SUMS.txt` — 파일 지문. 반입 승인 때 이 값을 함께 낸다. 같은 실행의 요약(Summary) 화면에도 적혀 있다.
3. 서명하지 않은 PyInstaller exe라 백신이 경고할 수 있다. 반입 절차(정보보안 점검)를 먼저 거친다.

## 2. 업무 PC에서 진단 (읽기 전용)

명령 프롬프트(cmd)에서:

```bat
filetidy-scan.exe scan --root C:\Users --root D:\ --root E:\ --out E:\파일정리_진단 --dest E:\
```

| 옵션 | 뜻 |
| --- | --- |
| `--root 경로` | 검사할 폴더. 여러 번 쓸 수 있다. C 드라이브는 범위가 정해지기 전까지 `C:\Users`처럼 사용자 폴더만 권장 |
| `--out 폴더` | 결과를 쓸 **새 폴더**. 다른 파일이 든 폴더는 거부한다. 같은 폴더로 다시 실행하면 이어서 한다 |
| `--dest 경로` | 정리본을 모을 드라이브. 남은 공간과 비교만 한다 |
| `--exclude 경로` | 추가로 뺄 폴더 (예: `--exclude D:\설치파일`) |
| `--exclude-pattern 패턴` | 추가로 뺄 이름 패턴 (예: `**/node_modules`, `/Users/*/OneDrive`) |
| `--no-default-excludes` | 기본 제외 목록(Windows, Program Files 등)을 쓰지 않음 |

진단을 마치면 `--out` 폴더에 다음이 생긴다.

| 파일 | 내용 | 밖으로 내보내도 되나 |
| --- | --- | --- |
| `진단보고서.html` | 한 장짜리 요약 보고서 (경로 포함) | **안 됨** — 업무 PC 안에서만 |
| `진단상세.xlsx` | 중복 파일·중복 폴더·포함 관계·오류 목록 (경로 포함) | **안 됨** |
| `scan.sqlite` | 전체 결과 DB | **안 됨** |
| `요약숫자.json` | 경로·이름 없는 숫자만 (파일 수, 용량, 묶음 수, 단계별 시간) | `mask_tool`로 한 번 더 확인한 뒤 숫자만 |

중간에 멈추면(Ctrl+C, 정전) 같은 `--out`으로 다시 실행한다. 이미 계산한 해시는 다시 쓴다.

### 배치 파일로 실행 (더블클릭용)

메모장에 아래를 붙여 넣고 **인코딩을 ANSI**로 저장(이름 예: `진단실행.bat`)해 exe 옆에 둔다.

```bat
@echo off
"%~dp0filetidy-scan.exe" scan --root C:\Users --root D:\ --root E:\ --out E:\파일정리_진단 --dest E:\
pause
```

## 3. 개인 PC에서 합성 정답셋으로 미리 해 보기

```bat
filetidy-testkit.exe generate --out C:\시험\정답셋
filetidy-scan.exe scan --sim-drive C=C:\시험\정답셋\data\C --sim-drive D=C:\시험\정답셋\data\D --sim-drive E=C:\시험\정답셋\data\E --out C:\시험\진단 --dest C:\시험
```

`--sim-drive 문자=경로`는 폴더 하나를 드라이브 맨 위처럼 다루는 시험용 옵션이다(제외 목록이 그 폴더 기준으로 적용됨).

## 4. 개발자용

```bash
pip install -r requirements-dev.txt
python -m pytest -q                       # 전체 시험 (리눅스에서는 윈도우 전용 시험이 건너뛰어짐)
python -m testkit generate --out /tmp/정답셋
python -m scanner scan --sim-drive C=/tmp/정답셋/data/C --sim-drive D=/tmp/정답셋/data/D --sim-drive E=/tmp/정답셋/data/E --out /tmp/진단
FILETIDY_SCALE=2000 python -m pytest tests/test_scale.py -s     # 규모 시험
FILETIDY_RANDOM_SEEDS=300 python -m pytest tests/test_random_trees.py   # 무작위 교차 시험 강하게
```

GitHub에 올리면 「시험·빌드」(`.github/workflows/windows.yml`)가 리눅스·윈도우에서 시험하고, 윈도우에서 exe를 만든 뒤
그 exe로 합성 정답셋을 진단해 정답과 맞는지 확인한다.
